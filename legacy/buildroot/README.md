# Старый прототип на Buildroot

До собственного ядра я подготовил прототип системы на Linux и Buildroot.
Он сохранён здесь отдельно и в сборке Malospal OS не участвует.

В конфигурации осталось прежнее рабочее имя MyOS. Полная сборка этого
прототипа не проверена. Сценарии рассчитаны на Linux или WSL.
