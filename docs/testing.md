# Проверка Malospal OS 0.1.0

Я проверил выпуск 7 ноября 2026 года в Windows. Использовал Python 3.12,
Zig 0.15.2, QEMU 11.1.0 и закреплённый Limine v8.7.0-binary.

```powershell
python kernel/tools/build.py check
```

Результат: **все 30 групп тестов на основной системе и 63 запуска QEMU прошли**.

| Проверка в QEMU | Запуски |
| --- | ---: |
| Обычная и тестовая загрузка BIOS/UEFI | 4 |
| Исключения и нарушения защиты памяти | 22 |
| Физическая память | 3 |
| Виртуальная память | 3 |
| Таймер и сохранение регистров | 3 |
| Последовательная консоль | 3 |
| Экран, прокрутка и работа без отдельных устройств | 6 |
| PS/2-клавиатура | 5 |
| Snake | 4 |
| Slots | 4 |
| USB-клавиатура и топология xHCI | 6 |

В тестах логики используется проверка неопределённого поведения UBSan.
Гостевые проверки выполняются с 32–256 МиБ памяти, через BIOS и UEFI,
с экраном и без него, с разными устройствами ввода.

В [testing-results.txt](testing-results.txt) я сохранил строки PASS из журнала.
Абсолютный путь к папке проекта заменён на `.`. Полные журналы, тестовые ядра
и снимки сохраняются локально в игнорируемой папке `kernel/build/`.

Скриншот консоли сделан при запуске обычного ядра. Снимки
[Snake](images/snake.png) и [Slots](images/slots.png) получены во время проверок.
Результаты выпуска относятся к QEMU; отдельную проверку новых файлов
на физическом компьютере я ещё не выполнял.
